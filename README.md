# Теплоход проекта 588 «Родина» — эскизная 3D-модель

Интерактивная модель речного круизного теплохода проекта 588 для просмотра в браузере:
корпус, три яруса надстройки, рубка, трубы, шлюпки, леера и расположение помещений на четырёх палубах
(нижней, главной, средней и шлюпочной).

**Открыть модель:** https://dimadali17.github.io/teplohod-588-3d/

## Что можно делать
- смотреть снаружи и «внутри» (прозрачные стены, цветные помещения с мебелью-схемой);
- показывать палубы по отдельности, с номерами кают;
- фильтровать помещения по типам, искать каюту по номеру или названию;
- кликом открывать карточку помещения: площадь, габариты, положение от кормы;
- делать продольный и поперечный разрезы;
- смотреть на «живое» судно: капитан, рулевой, матрос на баке, официанты, повар и пассажиры на прогулочных галереях и за столиками (можно выключить).

## Исходные данные и точность
- Общий вид и обводы: чертежи т/х «Родина» с [miniflot.ru](https://miniflot.ru/plans/PASS/Rod.php).
- Расположение помещений: схема палуб т/х «Святая Русь» (пр. 588) оттуда же.
- Главные размерения: L = 95,8 м, B = 14,3 м, T = 2,4 м.

Точность — около ±0,5 м; высоты палуб, мебель и подводная часть показаны схематично.
**Это эскиз, а не проектная документация**: перед реконструкцией всё нужно сверить с обмерами судна.

## Файлы
- `index.html` — страница просмотра (three.js);
- `npc.js` — люди на борту (фигурки и их маршруты);
- `model588.glb` — сама модель (открывается в Blender, SketchUp, Windows 3D Viewer);
- `rooms.json` — экспликация помещений (название, тип, площадь, габариты);
- `drawings/` — план главной палубы: PDF (A2, М 1:200) и DXF для AutoCAD / nanoCAD / КОМПАС;
- `tools/` — скрипты Python, которыми построены модель и чертёж.
